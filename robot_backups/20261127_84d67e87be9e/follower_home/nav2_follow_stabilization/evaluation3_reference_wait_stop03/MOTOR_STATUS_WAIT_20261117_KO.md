# 모터 상태 지연 대기·복구 (2026-11-17)

기존 reference-wait 평가3 진입점에 적용했다. 드라이버와 하드웨어 설정은 변경하지 않았다.
운영 중 상태 수신이0.3초 이상 끊기면 프로그램 종료 대신 양쪽 속도0으로 대기한다.
대기 시간 상한은 없다. 신선한 로컬 센서가 제공하는 실제 source stamp로 STOP을 보내며,
오래된 센서 시각을 현재 시각으로 고쳐 쓰지 않는다.

새 상태 수신 후 기존 driver 프로필·fault·feedback_fresh·epoch·armed를 확인하고,
원본 status_ros_ns가 신선하며 최소3개의 서로 다른 상태/피드백 표본과 정지 피드백을
1초간 안정적으로 관측한 뒤 같은 단계·같은arm으로 재개한다.
바퀴 속도는0부터 증가하도록 제어 ramp를 초기화한다.
대기 동안 추종/계획/핸드오프의 운영 타이머를 멈추며 겹친 참조 대기는 이중 합산하지 않는다.
종료 결과에 motor_status_wait_enabled/episodes/total_s를 추가한다.

실제 fault, 피드백 불량, 로컬 센서 이상, 드라이버 재시작(epoch 변경), 비무장 복귀는
자동으로 지우거나 재arm하지 않는다. 드라이버 명령·피드백·응답 watchdog은 그대로다.
따라서 드라이버 자체가 고장/재시작된 상황을 단순 메시지 지연으로 간주하지 않는다.
