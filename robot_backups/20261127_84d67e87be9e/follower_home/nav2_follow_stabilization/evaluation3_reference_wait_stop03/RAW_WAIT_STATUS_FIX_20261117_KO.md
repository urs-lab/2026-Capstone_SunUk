# 원시 오돔 지연 대기와 상태 발행 분리

관측 로그 local_avoidance_trial_1794903697263553303.jsonl: 참조 대기 진입 뒤 약 1.4초 로그 공백, RAW_STALE 예외로 종료, 모터에는 COMMAND_TIMEOUT이 기록됐다. 공백의 직접 원인은 아직 특정하지 못했다.

변경:
- 원시 오돔 원본 시각/수신 시각 .6초 초과 시 무기한 0속도 대기.
- 기다리는 동안 예전 오돔의 시각을 현재로 바꾸지 않는다. 기존 드라이버의 연속 모드 expired-source ZERO-only 계약을 사용한다.
- 원시 오돔과 스캔이 새 시각으로 갱신되고 모터 정지 피드백이 확인되는 상태를 1초 이상 유지한 뒤 재개. 이후 EKF/참조 검사도 모두 통과해야 실제 이동 가능.
- 잘못된/미래/누락 원시 입력과 IMU/스캔의 고장 검사는 유지.
- 표시용 /follower/local_avoidance/status만 별도 프로세스에서 발행. 고정 크기 최신값 슬롯, 부모 비차단 복사, 과거 메시지 재생 없음.
- 제어/선두/상태 발행, 그래프 검사, 콜백 처리, 로그 쓰기의 50ms 초과 구간을 slow_operations에 기록.

드라이버 코드는 바꾸지 않았다. .3초 제어 명령/피드백/응답 감시는 그대로이므로 명령 전달 자체가 계속 막히면 오류 정지는 발생한다. 이번 수정으로 모든 지연을 해결했다고 판단하지 않는다.

평가 실행기를 끈 상태에서 오류가 남은 모터 드라이버만 재시작한다. 센서/AMCL/중계기는 유지한다. 양쪽 정지/후발 비무장 상태에서 새 기준선 저장 뒤 평가 실행.
