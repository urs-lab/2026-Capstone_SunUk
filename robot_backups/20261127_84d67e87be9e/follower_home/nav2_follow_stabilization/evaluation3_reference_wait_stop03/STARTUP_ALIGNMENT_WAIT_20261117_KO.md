# arm 전 스캔 정렬 대기 누락 수정

local_avoidance_trial_1794904845710531421.jsonl: START 승인 후 선두 시작을 요청하고, 후발 arm 전에 core.scene()의 스캔-오돔 보간 실패가 그대로 예외로 빠져나갔다.

수정: START 직후 재검사 및 선두 시작 실측 대기에도 정렬 대기를 적용한다. 선두 명령 0, 후발 비무장으로 대기한다. 원본 시각의 새 스캔/EKF 장면과 양쪽 정지 상태가 1초 안정되고 3개 이상의 새 시각이 확인되면 같은 START 승인으로 시작 절차를 재개한다. 대기 시간은 기존 4초 선두 출발 관측 시간에서 제외한다.

미래/잘못된 입력, 실제 센서 고장, 모터 오류는 대기로 숨기지 않는다. 스캔 시각의 보간 조건 및 계획 후 자세 변경 검사도 유지한다. 3cm 정지/10cm 계획 여유 및 모터 감시는 그대로다.

이번 실행은 후발 arm 전 종료되어 드라이버 오류가 없으므로 드라이버/센서/중계기 재시작 없이 양쪽 정지 후 새 기준선 저장과 평가 실행만 다시 한다.
