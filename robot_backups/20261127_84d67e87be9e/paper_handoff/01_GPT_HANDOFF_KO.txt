2. 프로젝트 목적과 정확한 목표 구분
프로젝트는 ROS2 기반 두 이동 로봇의 선두·후발 연동 주행을 구현한다. 선두는 공유 지도에서 Nav2 목표 주행을 하고,
후발은 선두가 실제로 지나간 경로를 받아 추종한다. 별도 모드에서는 후발이 장애물을 회피하고 원래 경로에 합류한 뒤 추종을 이어간다.
정량목표1: 선두 Nav2 Goal 주행 + 후발 경로 추종. RViz의 선두 2D Goal로 시작.
정량목표2: 선두 단독 3m 전진을 동일 조건에서 총3회. 후진은 복귀/별도 시험이며 평가2 전진3회에 섞지 않음.
정량목표3: 직선 대열 주행 중 후발 앞 장애물 관측 → 회피 → 공유 지도상의 선두 경로 재합류 → 합류 후 추종.
목표3 실행 설정은 합류 후2m. 과거 설계보고서에 있는 '재합류 후1m 이상' 기준과 설정2m는 서로 구분.

5. 좌표계·위치추정 데이터 흐름
공유 전역 프레임 map.
선두: map → odom → base_link. 후발: map → follower/odom → follower/base_link → follower/laser, follower/imu_link.
바퀴 오뎀과 IMU를 로컬 EKF에 이용하고, AMCL은 기존 지도와 LiDAR 관측으로 지도 기준 위치를 추정한다.
후발 Bridge는 map 좌표 변환과 filtered odom 정보를 이용해 /follower/odom_map을 발행한다.
주요 후발 토픽: /follower/odom_raw, /follower/odometry/filtered, /follower/odom_map, /follower/scan, /follower/imu/data.
초기 위치 토픽: 선두 /initialpose, 후발 /follower/initialpose.
AMCL active만으로 주행 준비가 끝나지는 않는다. 초기 위치·스캔·연결된 TF·신선한 오뎀이 필요하다.
후발 public /tf와 /tf_static 구성이 마지막 공통 실행 경로다. private TF 실험 노드를 중복 실행하지 않는다.
LiDAR 장착 TF의 코드값: base_link 기준 x0.26m, y0, z0.24m, 후발 회전 quaternion(0,0,0,1).

6. 정량목표1의 실제 알고리즘
선두 Nav2의 smoothed cmd_vel → 별도 nav2_convoy_gate → 선두 모터 /cmd_vel.
후발은 /leader/path(_unicast)에 쌓이는 선두 실측 경로와 leader/follower 지도 위치를 이용한다.
/leader/path는 Nav2 전역 계획 경로 자체가 아니라 Bridge가 선두 이동 위치를 누적한 경로다.
DirectedPathTracker가 진행 방향·진행도를 고려해 전방 목표점을 고르고 Pure Pursuit로 조향한다.
후발 로봇 좌표의 목표점(x,y)에 대해 곡률 kappa=2*y/(x*x+y*y), 각속도 w=v*kappa 형태.
따라서 '경로를 따라가지 않고 Pure Pursuit로 선두 위치만 쫓는다'는 설명은 틀림. 경로 추종의 제어법이 Pure Pursuit다.
정량1 lookahead0.8m, 최대 명령 선속도0.1m/s, 후발15RPM, 기준좌표 사이 목표 간격1.5m.
속도는 필터링한 선두 속도와 간격 오차에 따라 조정. gap deadband0.05m, 후발 가속0.12m/s²·감속0.20m/s² 코드 설정.
최소 근접 판단1.0m는 추정 좌표 기준이며 실제 차체 외곽 간격1m를 보장하는 값이 아님.
선두 회전·후진, 간격 유지, 입력 지연에서 후발이 대기할 수 있다. 정량1은 LiDAR 거리 정지/장애물 회피 비활성 모드.
최신 goal1_flow_20261118은 기존 최고속도0.1m/s를 유지하고 상태 발행 주기를 단축하고 channel5 중계 대기를 제거했다.
선두 gate의 저속 출발 상한0.06m/s, 두 참조점 간격1.5m 이상에서 선두 상한 min(0.1,후발요청속도+0.02).
드라이버는 명시적 --wait-expired-reference일 때만 송신시 유효했지만 수신 중 만료한 측정값을 속도0으로 변환한다.
새 신선한 zero 명령과 실제 정지 피드백 후 hold 해제, 운영자가 아니라 operator가 안정 입력을 확인해 같은 세션에서 재개한다.
미래 시각·송신 전 만료·다른 epoch·과속·진짜 command/feedback/response fault는 계속 구분한다.
초기 실측경로가1점일 때 선두 저속 기동과 후발 정지 대기가 필요하며, 첫2점이 생기기 전 복구가 종료되던 누락도 별도 수정했다.

10. 주요 개발·문제 해결 이력
- private/public TF 혼합·초기위치/AMCL 상태 문제: public TF 체인과 입력 진단, 통합 실행으로 정리.

- callback 공정성 문제: persistent executor와 고정 timeout으로 callback 처리 구성.
- operator가 보는 IMU 지연과 독립 수신 기록 비교, 지연을 센서 자체 고장으로 단정하지 않고 수신 경로도 점검.
- AMCL lifecycle 시작 실패: 지도 파일은 읽었지만 change_state 응답 timeout이면 AMCL configure/activate 전에 멈출 수 있음.
  센서 후 위치추정 기동·준비확인·UDP XML 명시. bond20초 변경은 서비스 configure 응답 실패와 다른 단계임.
- /follower/odom_map 발행자2개: 통합 Bridge와 단독 복구 Bridge 중복. 현재 통합 실행1개만 사용.
- 목표1은 선두Nav2/gate 필요, 목표3는 해당 gate 종료. 서로 반대로 적용하면 graph/startup 차단.
- PATH_TIP_DIRECTION_MISMATCH_RESTART_BRIDGE: 선두 누적 경로 마지막 진행방향과 현재 yaw가90도 초과 불일치.
  후진 복귀/회전/초기위치 재지정 후 과거 경로가 남는 상황 가능. 위치준비 후 선두 Bridge 재시작과 새 기준선 저장.
- 테스트 복사에서 isolated_telemetry 누락: 새 candidate폴더에 원본 helper 복사, 상위경로 의존 제거.
  새 인터프리터와 실제 spawn/IPC(ROS·모터 없는 테스트)로 별도 확인. 이 검사는 실물 회피 성공과 다름.

11. 시계·통신 측정 해석
과거 세 장치 timedatectl 출력은 NTP active/synchronized=yes였지만 이는 모든 시점 오프셋0을 뜻하지 않음.
원본 source timestamp age, 로컬 receipt age, callback 대기, 계획 계산, 실제 이동 시간을 분리할 것.
UDP 중계 지연이나 DDS publish block을 모두 무선 신호불량 탓으로 단정하지 말 것.
새 백업 수집 메타데이터의 호스트시각과 사용자요청 기준일이 다르면 파일에 기록된 시각을 그대로 보존하고 버전 provenance에 명시할 것.

12. 관측·성과의 근거 수준
A. 사용자가 기능 동작 성공이라고 확인한 대화 이력: 11월13일 및17일 목표3 관련 성공 확인. 구체 정량 통과 수치와는 별개.
B. 실행 로그: 목표1 실제 DRIVE/WAIT/RESUME와 motor feedback, 목표3 회피·map rejoin/handoff 이벤트가 있는 기록.
C. 외부 실측: 목표2 3회합계9.05m 사용자 관측 등. 최종 시행별 실측표는 추가 필요.
D. 설정값: 최대속도, 간격, 여유, post-rejoin2m. 달성값으로 보고하면 안 됨.
E. 모의 시험/저장장면 계산 성능: 단위시험·회귀시험·정적 replay. 실물 검증 수와 합산하지 않음.
최종 시연이 끝났다는 사실은 확인됐지만 본 요청에 최종 점수·시도수·성공수·영상은 제공되지 않았다.

13. 논문 초안에서 쓸 수 있는 주장과 피해야 할 주장
가능: 서로 다른 두 로봇의 ROS2 기반 연동, 선두 실측 경로 추종, 후보 기반 국소 회피와 공유 지도 재합류의 구현.
가능: timestamp/TF/모터 피드백을 포함한 상태 기반 대기·복구 구조와 통신/제어 실행 분리의 설계 설명.
자료가 있어야 가능: 추종오차 개선율, 회피성공률, 평균계획시간, 최대반응시간, 제동거리, 최대최소간격, 반복성.
현재 불가: 오차0, 성공률100%, 모든 장애물 대응, 산업안전 인증, 완전 무인 운용, 신호끊겨도 계속주행, 새 알고리즘의 세계최초 주장.
정량1 장애물회피 비활성 사실과 초기위치 수동지정 사실을 숨기지 말 것.
